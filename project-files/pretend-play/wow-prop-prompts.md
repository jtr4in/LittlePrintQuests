# Wow-factor prop prompts for each kit (Gemini)

One realistic, life-size prop per kit: the piece a kid grabs first and a parent photographs. Think a real-looking X-ray to hold up to the window, a computer screen for the desk, a wooden pizza peel. Each prompt is complete on its own; paste it as is.

**Settings:** the highest resolution Gemini offers, at the aspect ratio given in each heading. Save as PNG named by the kit id (for example `vet.png`). If you make more than one for a kit, add a letter (`vet-b.png`).

**What I do with them:**
- Cut them out along their real outline and add a dashed cut line.
- Print the child's name or the shop name wherever a prompt leaves a blank screen, label or plate, since Gemini misspells text.
- Big props (the ones marked "2 pages") get split across two Letter sheets with a tape tab, so they print life-size.

**Why every prompt ends the same way:** a plain white background makes them easy to cut out cleanly, and "no text, no logos, no real brands" keeps them safe to sell.
